# QuestBoard local presentation data

Dedicated database and media tree for campus demos and screenshots.

| Piece | Value |
|---|---|
| Database | `questboard_presentation` |
| Media | `apps/backend/var/proof-media-presentation` |
| Classroom start | `bash scripts/start-demo.sh` (see `DEMO_START.md`) |

Credentials live in **`ACCOUNTS.local.md`** (gitignored). Do not commit passwords.

Local Vite helpers such as `start-demo.local.sh` are gitignored and are **not** used for the ChatGPT Sites classroom flow.
